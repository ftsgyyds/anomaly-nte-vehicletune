# 车辆调校 · Anomaly 插件

《异环》(Neverness To Everness) 的载具调校插件，运行在 [Anomaly](https://github.com/AnomalyNTE/Anomaly) 插件框架下。

作者：**雪不语 与 超级可爱的小助手芸汐**

## 功能

| 功能 | 说明 |
| --- | --- |
| 配件切换 | 车漆 / 胎烟 / 胎痕 / 涂装，点选即时生效，不卡顿 |
| 漂移轮换 | 每甩一次尾自动换下一个胎烟与胎痕；正常行车完全不切换，不打断换挡 |
| 底盘参数 | 极速、扭矩、转速、换挡转速、齿比、抓地、弹簧阻尼等滑块实时调整 |
| 配件预设 | 保存/套用整套配置；预设存于 `Anomaly\state\plugins`，重进游戏与插件更新都不丢 |

只修改本机载具数据，不影响其他玩家。

## 安装

### 方式一：在线安装（推荐）

1. 打开游戏内的 Anomaly 面板
2. 进入 **Plugins > 第三方插件**，点「添加插件源」
3. 填入：

```
https://raw.githubusercontent.com/ftsgyyds/anomaly-nte-vehicletune/main/pluginmaster.json
```

4. 回到 **Plugins > 可用** 刷新，找到「车辆调校」安装并启用

### 方式二：手动安装

1. 下载 Releases 里的 `nte.vehicletune-5.8.7.zip`
2. 解压到 `HT\Binaries\Win64\Anomaly\plugins\VehicleTune\`
3. 确保目录里直接能看到 `manifest.json` 和 `plugin.dll`

## 使用

进游戏后按 Anomaly 面板热键打开，选中「车辆调校」：

```
[刷新列表] [刷新配件列表]
平滑切换(bForceUpdate=0): 开
--- 底盘调校 ---        ← 各种参数滑块
>>> 应用所有已选配件 <<<
--- 配件预设 ---
--- 车漆 ---             ← 点选即时切换
--- 胎烟 ---
--- 胎痕 ---
--- 漂移轮换 ---         ← 胎烟/胎痕漂移触发开关
--- 涂装 ---             ← 含「00 无涂装」「01 原厂默认」
```

**漂移轮换**默认开启。想换成固定款式时把对应开关关掉，直接用上面的车漆/胎烟/胎痕列表点选即可。
